# Mare Nostrum - Riu de Llibres

## Descripció de la web
**Mare Nostrum** és la plataforma digital oficial d'una iniciativa cultural, solidària i literària a l'aire lliure (ambientada a Lleida) basada en la economia circular del llibre i la cultura lliure. 
El concepte principal gira entorn d'un **"Riu de Llibres"**: una intervenció on s'omplen els carrers i espais públics amb llibres donats perquè qualsevol ciutadà pugui passejar, agafar un llibre de manera gratuïta, endur-se'l o deixar-ne un a canvi. La web actua com a portal informatiu i de participació ciutadana, facilitant la consulta d'itineraris d'activitats (conferències, recitals, tallers), la inscripció de voluntaris i col·laboradors institucionals (com la Paeria de Lleida o la Diputació de Lleida).

## Tecnologies utilitzades
- **HTML5** (Estructura semàntica de les pàgines i seccions)
- **CSS3** (Disseny responsiu amb Flexbox, Media Queries i animacions de tipus slider)
- **JavaScript** (Interactivitat avançada, gestió de la modal de benvinguda amb `localStorage`, validació de formularis amb expressions regulars i efecte Lightbox per a la galeria d'imatges)

## Instruccions per executar-la localment
1. Clona o descarrega aquest repositori al teu ordinador.
2. Obre la carpeta del projecte amb un editor de codi (com ara Visual Studio Code).
3. Obre el fitxer `index.html` directament al teu navegador web preferit o utilitza una extensió de servidor local (com *Live Server*) per visualitzar-la correctament.
